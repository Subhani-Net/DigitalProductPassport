# CBAM Annual Declaration — Report Template

The **whole submission** (not a slice). One report per importer per reporting year.

---

## 1. Declarant & submission
- Declarant (EORI, name), role, reporting year, declaration due date.
- Status: draft / verifier-ready / verified (partner).

## 2. Scope summary
- CN codes, total quantity, number of source installations, determination mix (actual/default).

## 3. Declaration lines (the core)
| CN code | Installation | Country | Quantity (t) | SEE (tCO₂/t) | Embedded (tCO₂) | Determination | Evidence |
|---|---|---|---|---|---|---|---|

## 4. Aggregation by CN code (Art. 35)
| CN code | Total quantity (t) | Total embedded (tCO₂) |
|---|---|---|

## 5. Embedded emissions summary
- Total embedded (tCO₂e). SEE carries direct + indirect (+ precursors where applicable); component
  split is held in each installation dossier.

## 6. Certificate obligation
- CBAM factor for the year; any foreign carbon-price deduction; certificates to surrender; cost.
- (Show the 100%-factor illustrative cost for context.)

## 7. Actual vs default
- What the same quantities would cost on default values; the saving.

## 8. Evidence & provenance
- Each line links to its installation dossier (source documents, allocation, assumptions).

## 9. Assumptions register
- Every gap/estimate, flagged.

## 10. Attestation & verification status
- **Verifier-ready, not verified.** The accredited verifier's report is required to use actuals;
  the stamp is a partner verifier's (independence rule).
