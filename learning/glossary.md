## A. EU ETS & MRV data rules

| Term | Quick definition | Cover in | Status |
|---|---|---|---|
| **MRV** | Monitoring, Reporting & Verification — the cycle by which emissions are measured, reported, and independently checked. Underpins both EU ETS and CBAM. | 101 | ✅ |
| **EU ETS** | EU Emissions Trading System — cap-and-trade; operators surrender one allowance per tCO₂e. | 101 | 🔗 |
| **MRR** | Monitoring and Reporting Regulation (EU) 2018/2066 — EU ETS rules for how operators monitor/report emissions. | 201 | ✅ |
| **AVR** | Accreditation and Verification Regulation (EU) 2018/2067 — EU ETS rules for verifiers & accreditation. | 201 | ✅ |
| **EU ETS data rules** | The MRR + AVR + ETS Directive (2003/87/EC) family — the "data discipline" CBAM borrows. | 201 | ✅ |
| **Allowance (EUA)** | Right to emit 1 tCO₂e under the ETS. | 101 | ✅ |
| **Free allocation / benchmark** | Free allowances to industry by product benchmark; phased down 2026–2034 (mirrored by CBAM phase-in). | 201 | ✅ |
| **Union Registry** | The registry holding ETS accounts/allowances — *distinct from* the CBAM Registry. | 201 | ✅ |
| **Monitoring plan** | Document defining an installation's data boundaries, source streams, meters, calculation approach. | 201 | 🔗 |
| **Tier (1/2/3)** | Data-quality/uncertainty tiers used in MRV. | 201 | ✅ |
| **Activity data / emission factor / oxidation / conversion factor / NCV** | The calculation inputs (quantity × factor; net calorific value etc.). | 201 | 🔗 |
| **CEMS** | Continuous Emissions Monitoring System (stack measurement). | 201 | 🔗 |
| **Mass balance** | Determining emissions from the carbon balance of inputs/outputs. | 201 | 🔗 |

## B. CBAM-specific

| Term | Quick definition | Cover in | Status |
|---|---|---|---|
| **Authorised CBAM Declarant** | EU importer authorised to import covered goods; legally liable. | 101 | 🔗 |
| **Embedded emissions / SEE** | GHG to produce a good; SEE = specific, tCO₂e/t (direct + indirect + precursors). | 101 | ✅ |
| **Precursor / complex goods** | Covered input carried into a product; widens scope + footprint. | 101 | ✅ |
| **Actual vs default values** | Installation-verified vs EC-published fallback (punitive). | 101 | ✅ |
| **Definitive vs transitional period** | Financial regime (from 1 Jan 2026) vs reporting-only (2023–25). | 101 | ✅ |
| **AMM / O3CI / DRMC** | CBAM Registry modules (declarants / operators+verifiers / monitoring). | 101 | 🔗 |
| **NCA / verifier / accreditation** | National authority; accredited verifier issues the report. | 101 | 🔗 |
| **De minimis (50 t)** | Importer exemption below 50 t/yr. | 101 | ✅ |
| **Carbon-price deduction** | Deducting carbon already priced in the country of origin. | 101 | ✅ |

## C. Carbon accounting & standards

| Term | Quick definition | Cover in | Status |
|---|---|---|---|
| **GWP / AR6** | Global Warming Potential; IPCC AR6 values (e.g. CF₄ ≈ 7380, C₂F₆ ≈ 12400). | 201 | ✅ |
| **PFC / anode effect** | Perfluorocarbons from aluminium smelting anode effects; high GWP. | 201 | 🔗 |
| **Scope 1 / 2 / 3** | GHG Protocol categories (direct / purchased energy / value chain). | 201 | ✅ |
| **PPA / GO** | Power Purchase Agreement / Guarantee of Origin — for low-carbon electricity claims. | 201 | 🔗 |
| **LCA / EPD / PCF** | Life Cycle Assessment / Environmental Product Declaration / Product Carbon Footprint. | 301 | ✅ |
| **ISO 14064-3 / 14065 / 17029** | GHG verification + verification-body + validation/verification standards. | 301 | 🔗 |
| **Materiality / reasonable vs limited assurance** | Verifier thresholds and assurance levels. | 301 | ✅ |
