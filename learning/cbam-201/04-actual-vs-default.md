# Module 4 — Actual vs Default Values

## 4.1 The decision
For each good you either use:
- **Actual values** — installation-specific, primary data, **verified**; or
- **Default values** — Commission-published fallbacks (per CN code + country of origin). **Fact**.
The choice is per good/consignment and drives both **cost** and **verification effort**.

## 4.2 When defaults are allowed
- Where the operator cannot provide **verified** actual data. **Fact**.
- During the transitional period defaults were freely usable; in the definitive period the
  conditions are tighter and there is a **conservative mark-up** to discourage overuse.
  **Fact/Claim**.

## 4.3 The default catalogue & mark-up
- Default values for the definitive period: **IR (EU) 2025/2621**; benchmarks:
  **IR (EU) 2025/2620**. **Fact** (`../cbambok.md` §1).
- **Default-value mark-up** (conservative add-on): reported as **~10% in 2026 rising toward
  ~30% by 2028** for aluminium, cement, steel; **~1%** for fertilisers. **Claim [verify]**.

## 4.4 The economics — why actuals win
- At a certificate price near the ETS (~€75/t), a mark-up of 10–30% plus the gap between a
  plant's real performance and the conservative default can be a **large per-tonne penalty**.
  **Fact/Claim**.
- **Decision rule:** if the plant is even modestly better than the default, and the data is
  obtainable, **verified actuals almost always beat defaults** — and the saving grows as the
  **CBAM factor** rises (2.5% → 100%). **Logic**.

## 4.5 A practical decision tree

```
Is verified actual data available (or obtainable within budget/time)?
├─ Yes → use ACTUAL (verifier report required) → lowest long-run cost
└─ No  → use DEFAULT
        ├─ short term / first declaration → acceptable, budget for the mark-up
        └─ structural → invest in monitoring + verification (the wedge)
```
**Fact/logic**.

## 4.6 Determination flag
The declaration marks each product line's determination type (**actual vs default**) — this is
the core lever of the whole "defaults → verified actuals" business. **Fact**
(`../../research/cbam-data-catalogue.md` E5).
