# Outreach Pack

Customer-facing materials for the exporter-first wedge (importers/verifiers secondary).
Ties to `../presentation-plan.md` (the Present dimension) and the demo data pack (`../../demo/`).

| File | What |
|---|---|
| `funnel.md` | **Customer funnel** — 8 stages, conversion targets, channels, cadence |
| `leads-india-exporters.md` | **43 real Indian SME exporter leads** (pipes, forgings, aluminium extrusion, fasteners, castings) |
| `target-list.md` | Target-list template (personas + sourcing channels) |
| `exporter-one-pager.md` | The customer-facing one-pager (send after a warm reply) |
| `outreach-scripts.md` | Cold email + LinkedIn scripts (exporter primary, verifier, importer) |
| `trial-playbook.md` | **What to do when someone says "good for a trial"** |
| `consultant-channel.md` | **Consultant sourcing (Leafr) + engagement (co-development, not paid)** |

**Golden rule (from `../presentation-plan.md`):** solution-led, not probing. Show, don't interview.
Lead with a working demo, ask for a pilot — never "can I ask you about your pain."

## The one-line ask
> "I've built a working CBAM pipeline for steel. Want a 10-minute walkthrough — and if useful,
> a pilot on your data?"
