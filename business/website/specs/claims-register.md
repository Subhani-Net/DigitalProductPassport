## Rules

- **Earned** = evidence exists and is linked.
- **Prohibited** = must not appear on the site; remove if found.
- **Conditional** = allowed only with a named evidence artifact (e.g., a written review).
- Re-review this register on every website change and before publishing.

## Notes

- CBAM calculation basis: Reg. (EU) 2023/956 (Annex IV) + **IR (EU) 2025/2547**.
  The transitional **IR 2023/1773** is not the current definitive-phase basis.
- ISO 14064-1/14067 are adjacent standards, not the CBAM calculation method. ISO 14064-3 /
  14065 / 17029 describe assurance/verification.
