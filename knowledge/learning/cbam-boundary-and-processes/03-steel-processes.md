# Module 3 — Steel Processes (BF-BOF, EAF, DRI)

## 1. The three routes

```
BF-BOF:  coal → coke oven → coke ─┐
         ore → sinter/pellet ──────┼→ blast furnace → hot metal → BOF → crude steel
         limestone ────────────────┘                         │
                                                             ▼
                                              LF → casting → reheat → rolling → coating

EAF:     scrap + DRI/HBI + alloys + lime → electric arc furnace → crude steel → LF → casting → rolling

DRI:     iron ore pellets + natural gas/H₂ → shaft furnace → DRI → (EAF) → steel
```

A plant may have only part of a chain. A **re-roller** starts at HRC; a **caster** starts at
crude steel/pig iron; an **integrated** plant has the whole chain.

## 2. Process steps — purpose, inputs, outputs, what to ask

### 2.1 Coke oven
| | |
|---|---|
| Purpose | convert coal to coke (reductant) |
| Inputs | coking coal, heat |
| Outputs | coke, **coke-oven gas (COG)**, tar, benzole |
| Ask | coal invoices; coke output; COG meter and destination |
| Meters | coal weighbridge, gas flow, temperature |

### 2.2 Sinter plant
| | |
|---|---|
| Purpose | agglomerate ore fines for the blast furnace |
| Inputs | iron ore fines, coke breeze, limestone/dolomite, water |
| Outputs | sinter; off-gas |
| Ask | ore/limestone/coke breeze invoices; sinter output; off-gas treatment |
| Meters | weighbridges, gas flow, temperature |

### 2.3 Pellet plant (if present)
| | |
|---|---|
| Purpose | agglomerate ore into pellets |
| Inputs | iron ore, binder, fuel (gas/coal) |
| Outputs | pellets; off-gas |
| Ask | ore/binder/fuel invoices; pellet output |

### 2.4 Blast furnace (BF)
| | |
|---|---|
| Purpose | reduce iron ore to hot metal |
| Inputs | sinter/pellets, coke, **PCI coal**, limestone/dolomite, hot blast |
| Outputs | **hot metal (pig iron)**, slag, **blast-furnace gas (BFG)**, dust |
| Ask | burden mix, coke rate, PCI rate, hot-metal chemistry, BFG meter/destination |
| Meters | burden weighbridges, blast flow, BFG flow, temperature |

### 2.5 Basic oxygen furnace (BOF)
| | |
|---|---|
| Purpose | decarburise hot metal into crude steel |
| Inputs | hot metal, scrap, oxygen, lime/dolomite |
| Outputs | **crude steel**, slag, **BOF gas (BOFG)**, dust |
| Ask | hot-metal/scrap weights, oxygen, lime, BOFG recovery/destination |
| Meters | weighbridges, gas flow, oxygen flow |

### 2.6 Electric arc furnace (EAF)
| | |
|---|---|
| Purpose | melt scrap/DRI into crude steel |
| Inputs | **scrap, DRI/HBI, alloys, lime, electrodes**, electricity, oxygen |
| Outputs | **crude steel**, slag, off-gas, dust |
| Ask | scrap mix/chemistry, DRI share, electricity MWh, electrode consumption, oxygen |
| Meters | electricity meter, weighbridges, gas flow |

### 2.7 Ladle furnace / secondary metallurgy (LF)
| | |
|---|---|
| Purpose | refine chemistry and temperature |
| Inputs | crude steel, alloys, electricity, argon |
| Outputs | refined steel |
| Ask | alloys, electricity, argon; which steps are separate |

### 2.8 Casting
| | |
|---|---|
| Purpose | solidify steel into semi-finished shapes |
| Inputs | refined steel, mould flux, water, electricity |
| Outputs | **billets, blooms, slabs** (or ingots); scale; scrap |
| Ask | casting output by shape, yield, scrap returns |
| Meters | weighbridges, water/energy meters |

### 2.9 Reheat furnace
| | |
|---|---|
| Purpose | heat semi-finished steel for rolling |
| Inputs | billets/slabs, **fuel (NG, COG, BFG)**, air |
| Outputs | heated steel; flue gas |
| Ask | fuel invoices/meters per furnace; throughput; temperature |
| Meters | gas flow, temperature, weighbridge |

### 2.10 Hot rolling
| | |
|---|---|
| Purpose | roll into HRC, plate, sections, wire rod |
| Inputs | heated steel, electricity, water, rolls |
| Outputs | **HRC/plate/sections/wire rod**; scale; trim |
| Ask | output by product/CN, yield, electricity, scale |

### 2.11 Cold rolling
| | |
|---|---|
| Purpose | reduce thickness and improve surface |
| Inputs | HRC, electricity, rolling oil, water |
| Outputs | **CRC**; trim; oil waste |
| Ask | HRC input vs CRC output, electricity, yield |

### 2.12 Pickling
| | |
|---|---|
| Purpose | remove scale with acid |
| Inputs | HRC/CRC, acid, water, steam, electricity |
| Outputs | pickled coil; spent acid; rinse water |
| Ask | acid/water/steam consumption; throughput |

### 2.13 Coating (galvanising / painting)
| | |
|---|---|
| Purpose | corrosion protection / finish |
| Inputs | pickled/CR coil, **zinc/aluminium**, paint, fuel, electricity |
| Outputs | **coated coil**; dross; VOC; wastewater |
| Ask | coating mass, fuel, electricity, line speed, output |

### 2.14 Forging (if present)
| | |
|---|---|
| Purpose | shape steel by deformation |
| Inputs | billets/bars, **fuel/electricity**, dies, lubricants |
| Outputs | forgings; scale; trim |
| Ask | input/output mass, fuel/electricity, heat treatment |

## 3. DRI route (gas-based / H₂)

| | |
|---|---|
| Purpose | reduce pellets without coke |
| Inputs | iron ore pellets, **natural gas/H₂**, electricity |
| Outputs | **DRI**, top gas |
| Ask | gas/H₂ consumption, pellet input, DRI output, %Fe |

## 4. By-products and gases to record

| Output | Why it matters |
|---|---|
| **BFG** | used as fuel; affects direct emissions and allocation |
| **BOFG** | CO-rich; recovered/used/flared |
| **COG** | used as fuel; affects coal/coke accounting |
| **Slag** | co-product; allocation and mass balance |
| **Scale / trim / dust** | mass balance and yield |
| **Flared/vented gas** | often missed; count at origin |

## 5. What to ask (facts, per plant)

- Which of the steps above exist **on this site**?
- For each: inputs, outputs, fuels/gases, meters, and the documents.
- Which steps are **upstream** (precursors) rather than on-site?
- Which gases are **recovered, flared, vented, or exported**?
- What are the **yields** between steps?

## 6. Common mistakes

- Assuming every plant is integrated.
- Missing BFG/BOFG/COG (gas transfers are a classic gap).
- Treating HRC as an internal product at a re-roller (it is a **precursor**).
- Mixing crude steel and finished product quantities.
- Ignoring by-products in the mass balance.
