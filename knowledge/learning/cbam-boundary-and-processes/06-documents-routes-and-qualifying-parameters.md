# Module 6 — Documents, Routes and Qualifying Parameters

## 1. Existing documents to ask for

| Document | What it tells you | Ask for |
|---|---|---|
| **Monitoring plan** (ETS/CBAM) | boundary, source streams, meters, methods | full copy + version |
| **ETS records** (if EU) | prior verified emissions and methodology | permits, reports |
| **BRSR** (India) | sustainability disclosures, energy/emissions | report |
| **ISO 50001 / energy audit** | metered energy by use | audit report, EnMS data |
| **GHG report (ISO 14064-1)** | inventory boundary and emissions | report |
| **EPD / PCF** | product footprint (different boundary) | report + PCR |
| **Calibration certificates** | meter accuracy | per meter |
| **Mill certificates / CoA** | material properties, batch | MTC, CoA |
| **Customs / sales invoices** | CN codes and quantities | samples |
| **Utility bills** | electricity/gas volumes | full period |
| **Production logs** | output by product/period | export |

> Each document has a **date, version and owner**. Note them; a verifier will ask.

### What each document is good for — and not

- **EPD/PCF**: useful reference, but built on a different boundary — **not** a CBAM SEE.
- **BRSR**: company-level; may not align to the installation.
- **ISO 50001**: energy data, not emissions — good for cross-checks.
- **Monitoring plan**: the closest to what a verifier expects — but confirm it matches the current
  period and route.

## 2. Production routes

| Route | Description | Key data |
|---|---|---|
| **BF-BOF** | coke/sinter/blast furnace + basic oxygen furnace | coke rate, PCI, hot-metal ratio, scrap ratio |
| **EAF** | electric arc furnace on scrap/DRI | scrap mix, DRI share, electricity |
| **DRI** | direct reduction with gas/H₂ | gas/H₂ consumption, pellets, %Fe |
| **Primary Al** | alumina electrolysis | potline MWh, anode effects, cell technology |
| **Secondary Al** | remelting scrap | scrap mix, fuel, electricity |
| **Extrusion** | billet → profiles | billet input, yield, electricity, fuel |

## 3. Qualifying parameters (what changes the calculation)

These are the route-specific facts that select factors/methods. The exact list is set by the
implementing rules — **verify against Annex IV / IR 2025/2547**. **[verify]**

| Route | Typical qualifying parameters |
|---|---|
| BF-BOF | hot-metal ratio, coke rate, PCI rate, scrap ratio, ore/scrap mix |
| EAF | scrap ratio, DRI/HBI share, electricity per tonne |
| DRI | gas/H₂ type and consumption, pellet grade |
| Primary Al | cell technology (CWPB/PFPB/SWPB/HSS/VSS), anode effect, PFC factor set |
| Secondary Al | scrap mix, remelt fuel |
| Extrusion | billet source, yield, energy per tonne |

Ask for **values with a source** (production log, recipe, engineering record), not a label.

## 4. What to ask (facts)

- The monitoring plan and its version/date.
- Any ETS/BRSR/ISO 50001/GHG/EPD documents — and their boundaries.
- Calibration certificates for each meter.
- MTC/CoA samples.
- Customs/sales invoices with CN codes.
- Utility bills and production logs for the same period.
- Route-qualifying parameter values, with the record they come from.

## 5. Worked example

A BF-BOF plant claims “we are a modern, efficient plant.”
Facts to request: hot-metal ratio, coke rate, PCI rate, scrap ratio, BFG/BOFG/COG meters, and the
monitoring plan. The **numbers** select the method and the benchmark; the adjective does not.
