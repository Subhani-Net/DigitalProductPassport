# CBAM 101 — Foundations

**Status:** Complete · **Level:** Beginner · **Prerequisite:** none

CBAM 101 gives full conceptual command of the EU Carbon Border Adjustment Mechanism: what it
is, why it exists, who is in scope, how the machinery works, and how emissions are counted.
It is the language and map you need before any calculation or registry work.

## Learning outcomes
By the end you can:
1. Explain CBAM's purpose and its relationship to the EU ETS.
2. State the covered goods, the in-scope actors, and the 50 t de-minimis.
3. Trace the end-to-end flow (operator → verifier → Registry → declarant).
4. Describe embedded emissions (direct + indirect), actual vs default values, and precursors.
5. State the key obligations, dates, certificate mechanics, and penalties.

## How to study
1. Read modules 1–5 in order (20–30 min each).
2. Drill the cheatsheet until the key numbers are automatic.
3. Take the self-assessment; revisit any module you miss.
4. Keep `../../research/regulations.md` and `../../research/cbam-registry-workflow.md` open as the
   authoritative depth reference.

## Primary sources for this course
- Regulation (EU) 2023/956 (the CBAM Regulation).
- Implementing/Monitoring acts: IR 2023/1773 (transitional + methodology), IR 2024/3210
  (registry), IR 2025/2546 (verification), IR 2025/2547 (calculation, definitive),
  IR 2025/2621 (default values), Del. Reg. 2025/2551 (accreditation).
- EC CBAM Registry page + user manuals (DG TAXUD).
