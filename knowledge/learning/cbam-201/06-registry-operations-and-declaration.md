# Module 6 — Registry Operations & Declaration

## 6.1 Who does what in the registry
- **Non-EU operators** register in **O3CI** and upload installation + emissions data
  (confidential). **Fact**.
- **Accredited verifiers** review in the same O3CI portal and issue the **verification report**.
  **Fact**.
- **Importers (declarants)** work in **AMM** — authorisation + annual declaration + certificates.
  **Fact**.
- Access: **EU Login + 2FA**, via the **EU Customs Trader Portal**; the definitive Registry
  supersedes the transitional one. **Fact/Claim**.

## 6.2 The operator (supplier) flow — O3CI
1. EU Login + 2FA → access request (company docs, proof of representation).
2. Register as **Registered Operator**.
3. Upload installations + emissions data (activity data, direct + indirect, evidence).
4. Verifier reviews → verification report enables **actual values**. **Fact**.

## 6.3 The declarant (importer) flow — AMM
1. Apply for **authorisation** (stakeholder / activity / financial incl. **guarantee**);
   NCA assessment up to **120 days**. **Fact**.
2. Share **EORI** with the supplier → retrieve verified data (Emissions tab / third-country
   installations search). **Fact**.
3. Assemble the **annual declaration** (see 6.4).
4. Buy/hold/surrender certificates; meet the **quarterly minimum holding** (≥50% from 2027). **Fact**.

## 6.4 Declaration assembly — the fields
Per Art. 35 Reg 2023/956 + QReport-style structure (`../../research/cbam-data-catalogue.md` H):
- declarant identity + **EORI**
- per CN code: quantity (net mass), origin
- **actual total embedded emissions** (direct + indirect)
- **carbon price due in the country of origin** (deductible)
- **certificates to surrender** (after the **CBAM factor** and any deduction)
- **verification reports** where actual values are used

**Fact**.

## 6.5 Periodic mechanics
- **Annual declaration + surrender:** by **30 Sep** following import year (first 30 Sep 2027). **Fact**.
- **Certificate sales:** from **1 Feb 2027** on the common central platform. **Fact**.
- **Quarterly holding:** ≥50% of year-to-date emissions (from 2027). **Fact**.
- **Sell-back:** request by **30 June**; capped. **Fact**.
- **Penalty:** €100/tCO₂e per missing certificate; 3×–5× if importing without authorisation. **Fact/Claim**.

## 6.6 Ops hygiene
- Keep **evidence attachments** (CoA, MTC, monitoring docs, verification report) linked to lines.
- Validate **IDs/codes** and **decimal/units** before submit (format rules in the data catalogue H5).
- Version the declaration; reconcile via **DRMC**.
