# CBAM 201 — Practitioner

**Status:** Complete · **Level:** Intermediate · **Prerequisite:** CBAM 101 complete

CBAM 101 gave you the language and the map. CBAM 201 makes you **executable**: you can compute
embedded emissions, judge actual vs default, assemble a declaration, run the registry flows,
and prepare verifier-ready evidence — the day-to-day work of a CBAM practitioner.

> Depth reference: `../cbambok.md` (BOK) · `../../research/cbam-data-catalogue.md` ·
> `../../research/cbam-input-sources.md` · `../../research/cbam-registry-workflow.md`.

## Learning outcomes
By the end you can:
1. Apply Annex IV / IR 2025/2547 methodology: system boundaries, functional unit, SEE formula.
2. Choose and defend a calculation method (calc-based, CEMS, mass balance).
3. Read/author a **monitoring plan** and judge data quality (tiers, uncertainty, metrology).
4. Locate the data in real systems (ERP/MES/LIMS/utility/OT) and design the collection path.
5. Decide **actual vs default** and quantify the cost consequence.
6. Handle **precursors / complex goods** and work a steel + aluminium example.
7. Operate the **CBAM Registry** and assemble a declaration.
8. Prepare a **verifier-ready dossier** and understand ISO 14064-3 review.
