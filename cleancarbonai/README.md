## Reading discipline

- Every claim carries `> Source:` (page URL).
- "Claim:" = marketing statement; "Verbatim:" = copied text; "Fact:" = regulatory fact
  (independently verifiable in EU law, cross-check with `../research/regulations.md`).
- Nothing here is hallucinated filler; if a page did not state something, the section says
  "NOT FOUND".
